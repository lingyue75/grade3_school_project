## 五、三格式怎么用

| 格式 | 用途 |
| --- | --- |
| `.json` | 程序消费、追溯矩阵与后续自动化；含完整嵌套结构（访谈轮次、RACI、治理规则） |
| `.md` | 人读、评审、打印；每份都带演练声明与元信息 |
| `.csv` | Excel 筛选、按角色/状态/优先级做透视；单行扁平记录，utf-8-sig 编码 |

## 六、使用边界

1. 六人访谈完整 **不等于** 四来源收敛或需求已确认；Brief 与 Industry 两来源仍缺失。
2. 覆盖率 15/36，未覆盖的 21 项不得推断，见《现状信息请求表》。
3. 耗时、单量、损失金额、审批人清单、接口读写权限均未核实，不得作为需求依据或对外口径。
4. 演练结果不得作为实际业务指令（f40）；任何正式结论须授权人员确认（f41）。
5. 修改内容请改 `scripts/generate_briefs.py` 后重跑，不要单独手改某个格式的文件。
