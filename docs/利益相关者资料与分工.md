## 四、异常升级路径

1. A1 装卸口时间重叠：唐映秋处理 → 林亦舟复核 → 顾明岚升级
2. A2 排期表与邮件不一致：逐项核对 → 回填 → 通知受影响方
3. A3 跨工具取数：人工导出 → 字段对齐（f31）→ 缺失值与未确认值分列
4. A4 来源不清：退回补充，不得进入正式流转（f40）
5. A5 口径冲突：销售与运营书面确认 → 顾明岚定口径（f50 / f52）

## 五、停止试点的触发条件（傅景行使停止权，f04）

- 来源不清仍流转（f40）
- 未授权访问跨企业资料（f41）
- 自动锁档或承诺容量（f05 / f52）
- 以虚构样本对外表述（REQ-6）
- 版本无法追溯（REQ-3）

> 系统只提示冲突、不锁档；上述停止条件用于试点治理，不授予系统自动处置权。
