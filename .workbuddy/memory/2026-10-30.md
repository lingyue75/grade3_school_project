已定技术决策（后续沿用）：
- 四层：入口层（FastAPI + SSE，中间件链）→ 服务层（不碰 LLM）→ 智能体编排层（LangGraph/自研状态机 + Tool Registry + Guardrails + LLM Provider 抽象）→ 数据层（PostgreSQL16 + pgvector + Redis + 对象存储 + Celery）。
- 层间纪律：入口层不碰 ORM；服务层不碰 LLM；编排层只能通过 Tool 调服务。
- 知识库**按条款切片**（不按字数），每片带 metadata（适用职级/生效区间/制度版本），检索做结构化过滤 + 向量召回 + BM25 混合。
- 金额一律 numeric(14,2)；草稿保存 grade_code_snapshot 与 ruleset_version 快照；messages 表存 retrieval_refs 与 prompt_version 以支持回溯。
- 第一周 MVT = 问制度（带条款引用）+ 一句话建单 + 硬规则阻断；不做鉴权/预算/OA/前端美化。失败判据：问答准确率<50% 改切片策略；工具调用成功率<80% 改槽位填槽式确定性流程。
