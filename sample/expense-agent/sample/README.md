# 演练样例（虚构数据）

本目录存放**全部虚构的演示数据**，仅用于原型演示、评测与培训，不代表任何真实企业制度。

| 文件 | 内容 |
|---|---|
| `data/差旅报销制度.md` | 演练用《员工差旅与费用报销管理制度》（含职级差旅标准、票据要求、审批流程） |
| `demo_seed.py` | 演示账号（admin/1001）与演示票据（含 1 张已使用，用于验证重复报销拦截） |

## 与代码的关系

- 服务启动时会读取本目录：导入制度文档、写入演示账号与票据（`src/main.py`、`src/db.py`、`src/agent/schema.py`）。
- 生产部署：**删除本目录即可关闭全部演示数据** —— 代码中对 `sample.demo_seed` 做了 `try/import` 兜底，
  导入失败会跳过种子写入，不会报错。

## 替换成真实数据

1. 删除 `sample/data/差旅报销制度.md`，改用管理后台上传真实制度文档（Markdown 或 PDF）。
2. 删除 `sample/demo_seed.py`，改由 HR/主数据同步写入 `users` 表。
3. 票据改为从邮箱/卡包归集（见 `docs/需求清单-一页纸.md` Q1 决策）。

> 提醒：制度文档上传后请务必在管理后台【分片预览】页核对切片质量——
> 一个分片只应讲一件事，切片质量直接决定检索准确率。
