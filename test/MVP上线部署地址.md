## 二、站点能做什么

这不是说明页，而是**可在浏览器内运行冲突检测、并分角色查看的 MVP**。两端共用同一份内嵌数据与 `detectAll` 规则，判定口径完全一致。

| 端 | 面向 | 功能 |
| --- | --- | --- |
| **客户端** `index.html` | 员工 / 一线业务人员 | 选区域 → 运行冲突检测 → 检出 11 条提示（原因、关联单号、来源、「仅提示·不锁档」标记）；按四类冲突筛选；占档三态分布（f31）；30 条档期样本表；测试摘要与五条红线 |
| **管理端** `admin.html` | 管理员 / 审核与质量负责人 | **只读**：6 项 KPI（样本 / 交接 / 冲突 / 已确认占用 / 锁档数 / 证据率）；**红线自检** 5 项实时计算（f05/f52、f40、f31、f41、f02）；11 条冲突明细可按类型筛选；三态分布；从 `scenarios.json` 汇总的五类场景实测；**人工复核记录表**如实标记 `review_records=0` / 待授权人员复核 |

管理端刻意**不提供**任何写能力：无锁档、无改期、无提交审批、无删除、无规则修改，也不伪造复核结论——能力边界即安全边界。
### 管理端登录（演示门禁）

打开管理端会先看到**用户名 / 密码登录界面**，客户端无需登录。演示账号：

| 角色 | 账号 / 密码 | 结果 |
| --- | --- | --- |
| 管理员 | `admin / admin123` | 进入管理端（只读） |
| 员工 | `1001 / 123456` | **拒绝**，提示「员工角色无管理端权限，请返回客户端」 |

支持回车提交、`sessionStorage` 会话保持（刷新不重复登录）与右上角「退出登录」；口令在生成的页面中只以散列摘要参与比较。
**这是静态演示门禁，不是真实鉴权**：校验在浏览器内完成，页面源码与数据仍可被查看，生产系统必须由服务端做身份认证与接口级鉴权。

## 四、边界（务必如实表述）

| 边界 | 说明 |
| --- | --- |
| 静态演示，非生产系统 | 无服务端、无数据库、无登录鉴权、不写任何业务数据；数据全部内嵌为合成演练样本 |
| 管理端非权限隔离 | 「管理端」是**演示视图拆分**，不是真实权限控制：知道链接即可访问，没有角色校验；生产系统必须另做鉴权 |
| 不提供写操作 | 两端都没有锁档、改期、提交审批、对外承诺、删除等能力，管理端只读（f05/f52） |
| 正式系统在哪 | 完整 CLI 冲突检测、30 样本回放与 Agent 编排在本地仓库 `venue-schedule-tool/src/`，**未部署为生产服务** |
| 数据性质 | 30 条档期与 30 条交接均为演练虚构；45 单/月、35 分钟/单等数字不得作为基线或对外引用（REQ-6） |
| 已知口径 | 端点相接按闭区间判为重叠，须业务方书面确认后才能调整（见《测试方案》K-01） |
| 上线前置条件 | Brief 书面原文、Industry 适用性、损失口径、审批人清单仍待补，本站点**不代表试点已获签核或已上线生产** |

## 五、更新与下线

| 操作 | 方式 |
| --- | --- |
| 更新页面内容 | 改 `scripts/build_site.py` → 运行 `python scripts/build_site.py`（同时重建 `index.html` 与 `admin.html`）→ 重新发布同一目录（链接保持不变） |
| 更新演练数据 | 改 `data/slots.csv` / `data/handovers.csv` → 重跑构建脚本 → 重新发布 |
| 更新测试摘要 | 重跑 `scripts/run_scenario_tests.py` 生成 `test/scenarios.json` → 重跑构建脚本 → 重新发布 |
| 一致性回归 | 修改规则后须重跑 `pytest tests/ -q` 与 30 样本回放，并重新做第三节的 JS / Python 对照 |
| 下线 | 在应用管理入口将该应用下线，分享链接随即失效 |
