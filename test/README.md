## 五、再生成方式

```bash
cd venue-schedule-tool
python scripts/run_scenario_tests.py   # 输出写入仓库顶层 test/
```

- 输出目录可用环境变量 `VENUE_TEST_DIR` 覆盖，便于临时验证而不污染交付目录。
- 该脚本每次运行会刷新执行时间与耗时毫秒，使 `.md` / `.png` / `.json` 变化；若只做验证、不打算更新交付物，运行后请还原生成物，或同步重生成 6 份 docx（5 份需重新插图）以免 md 与 docx 不一致。
- `.docx` 由同名 `.md` 经本地编辑器转换；改内容先改 `.md` 或生成脚本。
