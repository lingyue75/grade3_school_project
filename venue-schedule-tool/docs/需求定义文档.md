## 三、AI 改造点与优先级

### 3.1 排序方法

按「业务结果 × 不可逆风险」双轴排序，逐项回答四问：改善什么结果、失败何时被谁看见、能否在损害前拦截、是否可撤销。**不以模型置信度代替业务风险**；价值或风险未知先补证据，不排高优先级。

### 3.2 改造点清单

| 编号 | 改造点 | 类型 | 对应痛点 | 输入 → 输出 | 人工确认点 | 失败方式 / 可拦截性 | 优先级 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| A1 | 统一关联编号与字段治理 | 数据治理（确定性） | P2 / P4 | 三类工具只读导出 → `DLG-YYYYMMDD-NNNN` 贯通、字段对齐 | 秦芮核对字段映射 | 导出失败即停，不写入生产；可重跑 | **P0** |
| A2 | 区域 / 装卸口冲突检测引擎 | 确定性规则（非 LLM） | P3 | 区域、时间窗、进撤场时长 → 重叠提示（原因 + 依据单号） | 林亦舟复核提示 | 只读、无副作用、可回放；**可拦截、可撤销** | **P0** |
| A3 | 交接三项齐套检查 | 确定性规则 | P1 | 接收人 / 版本 / 未结项 → 缺项拦截并列出待补内容 | 唐映秋核对交接记录 | 缺项即退回，不产生新状态 | **P0** |
| A4 | 来源留痕与复核台账 | 流程留痕 | P5 | 每条提示 → 来源 + 人工复核记录 + 30 样本回放报告 | 傅景按 f02 口径检查 | 只追加，不可篡改；审计可追溯 | **P0** |
| A5 | 占档状态三态模型 | 数据治理 | P4 | `confirmed` / `unconfirmed` / `missing` → 分列展示 | 秦芮抽样核对 | `missing` 不参与时间窗判定，只报「数据不完整」 | **P0** |
| A6 | 冲突原因与依据自动生成 | 模板化生成（可用小模型润色，不裁决） | P3 / P5 | 冲突对象 → 原因说明、影响对象、条款 / 单号引用 | 人工复核措辞 | 不得生成结论或对外承诺；可关闭 | P1 |
| A7 | Agent 编排与变更请求前人工确认中断 | LLM 辅助（只做意图与摘要） | P1 / P5 | 自然语言诉求 → 工具调用序列 + 变更请求预览 | **授权人员（傅景 / 顾明岚）确认后才创建请求** | 工具集不含 `lock_slot` / `sign_contract` / `commit_capacity`；stamp 防跳步 | P1 |
| A8 | 制度口径知识库问答 | RAG（只答制度，不裁决） | P6 | 制度文档 → 带条款引用的回答 | 顾明岚确认口径 | 检索为空须答「制度中未找到」，不得推测 | P2 |

### 3.3 明确不做（能力边界即安全边界）

1. **不做**自动排期、自动锁档、自动改期、自动签约、自动承诺容量（f05 / f52）。
2. **不做**自动对外承诺，不替业务方回复「档期已调整」。
3. **不做**把「已处理」自动写成结论；正式结论只能由授权人员确认（f41）。
4. **不做**来源不清的申请自动流转；来源存疑一律退回补充（f40）。
5. **不做**基于虚构样本测算收益、不承诺量化改进（REQ-6）。

> 选型判断：A1–A5 是**确定性能力**，与「智能」无关，却是全部价值与安全的地基，必须优先；LLM 只用于 A6–A8 的解释、意图与检索，**不进入任何判定与写入路径**。试点期自主度定为 **L1（Agent 建单、人点确认）**。

### 6.3 拒绝条件与停止条件

- **拒绝条件**：来源不清仍流转（f40）、未授权访问跨企业资料（f41）、自动锁档或承诺容量（f05 / f52）、以虚构样本对外表述、30 样本回放出现漏报或无原因说明。
- **停止条件**：由傅景行使停止权（f04）；触发条件与检查项须在试点启动前书面确认，**当前尚未核实，不得写入正式验收**。
- **签核方式**：书面确认记录，注明评审人与日期；保留 f50 / f52 分歧与 Brief / Industry 待补来源，交下一阶段承接。

## 八、结论

本项目的最小可验证方案是「**A 人工优化 + B 确定性规则 + C 模型仅辅助**」：先把交接三项、统一编号、三态口径与来源留痕做实，再在提交与交接节点提供可解释的冲突提示；**判断权与承诺权始终留在人手里**。该方案价值明确、失败可在损害前拦截、且全部改造可撤销，符合单批次试点的风险约束。

AI 改造的优先级由此确定：**P0 五项全部是确定性能力，P1 两项才引入模型，P2 一项仅作问答辅助**。任何「让模型自动排期 / 自动决定能否变更」的方案，都在本需求边界之外。
