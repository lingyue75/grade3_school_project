## 格式约定

| 格式 | 说明 |
| --- | --- |
| `.json` | 完整结构化数据，含嵌套的访谈轮次、治理规则、RACI；供程序消费与追溯 |
| `.md` | 人读版，含演练声明、表格与逐字稿；可直接打印评审 |
| `.csv` | 扁平单行记录，`utf-8-sig` 编码，Excel 直接打开；每行带「演练声明」列 |

## 再生成

```bash
python scripts/generate_briefs.py
```

所有文件由同一脚本从 `discovery-report.json` 与本脚本内的结构化资料渲染，
**不要单独手改某一格式的文件**；需要变更请改脚本后重跑，保证三格式一致。
