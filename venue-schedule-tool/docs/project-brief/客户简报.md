## 二、三条不可突破的红线

1. 关键字段：场馆区域、时间窗、进撤场时长、版本、占档状态；占档状态三态区分，缺失值与未确认值必须分列
2. 只提示冲突，不自动锁档 / 签约 / 承诺容量
3. 正式结论须授权人员确认；跨企业资料只按明确授权范围访问
4. 来源不清的申请不得进入正式流转
