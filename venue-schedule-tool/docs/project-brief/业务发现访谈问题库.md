## 一、提问原则

1. 先问最近一单的具体事实，再问一般性规则，避免受访人给理想流程。
2. 受访人明确说「尚未核实」时，登记为待补信息，不得诱导其给估计值。
3. 涉及金额、单量、耗时必须先确认口径，再记录数字。
4. 涉及权限与红线的问题必须落到具名责任人，不接受「由相关同事处理」。
5. 陷阱题用于检验口径：状态缺失不得判为未占用；不得承诺档期已改。

## 三、陷阱题判定口径

- **Q-22**（状态未填是否等于没占档）：正确回答必须是**数据不完整、无法判断**，并区分 `missing` 与 `unconfirmed`（f31）。
- **Q-26**（能否告诉客户档期已调整）：正确回答必须是**须业务人员确认，系统只提示冲突**（f05 / f52）。
- **Q-18 / Q-02**（最近一次损失多少）：受访人拒绝给出无来源数字属**正确行为**，不得据此编造基线（REQ-6）。
- 上述三题若被答成「没冲突 / 已改期 / 具体金额」，应记为口径偏差并回到《现状信息请求表》补证。
