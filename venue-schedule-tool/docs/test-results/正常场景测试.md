- 项目：上海东浩会展经营有限公司 · 场馆排期与需求变更数智化试点（演练）

- 执行器：`scripts/run_scenario_tests.py`（真实调用 src/ 模块，无 mock）
- 说明：本场景共 5 条用例；图见文末附图。

| 指标 | 数值 |
| --- | --- |
| 用例总数 | 5 |
| 通过（PASS） | 5 |
| 已知口径（KNOWN） | 0 |
| 失败（FAIL） | 0 |

## 三、测试过程（逐条）

### N-01 30 样本回放：识别全部已标注冲突且说明原因

| 项 | 内容 |
| --- | --- |
| 输入 / 操作 | data/slots.csv（30 行）+ data/handovers.csv（30 行）→ detect_all → replay_report |
| 预期行为 | 输出 >=1 条冲突提示，每条含原因与来源，且不出现自动锁档 |
| 量化阈值 | 冲突数 >=1；有原因率 =100%；有来源率 =100%；自动锁档数 =0 |
| **实测输出** | 检出 11 条冲突（区域7/装卸口1/版本1/交接2），回放报告 {'total_conflicts': 11, 'all_with_reason': True, 'all_with_source': True, 'auto_lock_used': False, 'review_records': 0} |
| 实测指标 | 样本数=30；交接记录数=30；冲突提示数=11；有原因率%=100.0；有来源率%=100.0；自动锁档数=0 |
| 耗时 | 11.58 ms |
| **判定** | **PASS** |
| 备注 / 发现 | 对齐 f02 验收口径；四类冲突类型均有覆盖 |

### N-03 同区域时间窗重叠检出

## 四、实测发现与结论

- **N-01**（PASS）：对齐 f02 验收口径；四类冲突类型均有覆盖
- **N-02**（PASS）：编号规则 f30
- **N-03**（PASS）：同区域+同装卸口会同时触发两类提示，属预期设计
- **N-04**（PASS）：open_items='无' 视为「确认无未结项」，与缺失值 None 区分（f31）
