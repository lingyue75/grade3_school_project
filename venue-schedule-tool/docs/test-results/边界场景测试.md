# 边界场景测试

> **企业名称与公开业务方向有公开来源；人物、档期单号、时刻与指标均为演练虚构，不代表企业实际情况。演练结果不得作为实际业务指令（f40），正式结论须授权人员确认（f41）。**

- 项目：上海东浩会展经营有限公司 · 场馆排期与需求变更数智化试点（演练）
- 版本 / 日期：v1.0 / 2026-11-06
- 执行器：`scripts/run_scenario_tests.py`（真实调用 src/ 模块，无 mock）
- 说明：本场景共 6 条用例；图见文末附图。

## 一、场景目标与量化阈值

验证临界值与三态口径，暴露判定口径而非擅自改代码

| 指标 | 数值 |
| --- | --- |
| 用例总数 | 6 |
| 通过（PASS） | 5 |
| 已知口径（KNOWN） | 1 |
| 失败（FAIL） | 0 |
| 通过率（PASS / PASS+FAIL） | 100.0% |
| 合计实测耗时 | 0.28 ms |
| 单条最长耗时 | 0.12 ms |

> 判定口径：符合预设阈值记 PASS；不符合记 FAIL；实测符合当前实现但业务口径尚待书面确认的记 KNOWN，不计入通过率分母。

## 三、测试过程（逐条）

### B-01 端点相接是否判重叠（闭区间口径）

| 项 | 内容 |
| --- | --- |
| 输入 / 操作 | A 08:00-16:00 / B 16:00-18:00，同区域同装卸口 |
| 预期行为 | 记录当前实现口径：闭区间判定为重叠；该口径需业务方书面确认 |
| 量化阈值 | 冲突数按实现记录，不擅自改核心代码；标注为已知口径 |
| **实测输出** | 端点 16:00 相接，当前实现判 2 条冲突 |
| 实测指标 | 冲突数=2；判定区间=闭区间 a_start<=b_end 且 b_start<=a_end |
| 耗时 | 0.12 ms |
| **判定** | **KNOWN** |
| 备注 / 发现 | 已知口径：业务上「撤场结束=进场开始」是否算冲突尚未书面统一；修改会影响 30 样本回放既有结果，须先由顾明岚/傅景确认 |

### B-02 无重叠时不得虚报冲突

| 项 | 内容 |
| --- | --- |
| 输入 / 操作 | A 08:00-15:59 / B 16:00-18:00 |
| 预期行为 | 0 条冲突提示 |
| 量化阈值 | 冲突数 =0 |
| **实测输出** | 间隔 1 分钟，检出 0 条 |
| 实测指标 | 冲突数=0；间隔分钟=1 |
| 耗时 | 0.04 ms |
| **判定** | **PASS** |
| 备注 / 发现 | 无误报 |

### B-03 missing 状态不参与时间窗判定

| 项 | 内容 |
| --- | --- |
| 输入 / 操作 | 同区域两单，其中一单 status=missing |
| 预期行为 | missing 档期被排除，不得输出「无冲突 / 有空档」结论 |
| 量化阈值 | 参与判定记录数 =1；冲突数 =0；输出须可标注数据不完整 |
| **实测输出** | missing 记录被排除，冲突 0 条；工具层另报「数据不完整」 |
| 实测指标 | 参与判定记录数=1；冲突数=0；missing 排除=True |
| 耗时 | 0.03 ms |
| **判定** | **PASS** |
| 备注 / 发现 | 关键：不得据缺失值推断「没占档」（f31） |

### B-04 统一编号序列边界与非法输入

| 项 | 内容 |
| --- | --- |
| 输入 / 操作 | seq=1 / 9999 / 0 / 10000；date='2026116' / 'abcdefgh' |
| 预期行为 | 合法边界生成 0001 / 9999；越界与非法日期抛 ValueError |
| 量化阈值 | 合法数 =2；异常数 =4 |
| **实测输出** | 合法=['DLG-20261106-0001', 'DLG-20261106-9999']；正确抛出 ValueError 4/4 次 |
| 实测指标 | 合法值=['DLG-20261106-0001', 'DLG-20261106-9999']；合法数=2；异常数=4 |
| 耗时 | 0.02 ms |
| **判定** | **PASS** |
| 备注 / 发现 | 输入校验在编号生成层完成 |

### B-05 装卸口字段缺失

| 项 | 内容 |
| --- | --- |
| 输入 / 操作 | 同区域时间重叠，但 dock=None |
| 预期行为 | 不产生 dock_time_overlap，仅可能产生区域重叠 |
| 量化阈值 | 装卸口冲突数 =0 |
| **实测输出** | dock=None 时装卸口冲突 0 条，区域冲突 1 条 |
| 实测指标 | 区域冲突数=1；装卸口冲突数=0 |
| 耗时 | 0.06 ms |
| **判定** | **PASS** |
| 备注 / 发现 | 缺字段时不做装卸口推断 |

### B-06 未结项「确认无」与「缺失」区分

| 项 | 内容 |
| --- | --- |
| 输入 / 操作 | open_items='' / open_items=None / open_items='无' |
| 预期行为 | 空串与'无'为 0 缺失项；None 为 1 缺失项 |
| 量化阈值 | 三项判定全部精确匹配 |
| **实测输出** | missing_items 结果 {'空串': 0, 'None': 1, '无': 0} |
| 实测指标 | 空串=0；None=1；无=0 |
| 耗时 | 0.01 ms |
| **判定** | **PASS** |
| 备注 / 发现 | 注意：CSV 读入时空字段会转为 None，因此「没填」与「确认无」必须分列 |

## 四、实测发现与结论

- **B-01**（KNOWN）：已知口径：业务上「撤场结束=进场开始」是否算冲突尚未书面统一；修改会影响 30 样本回放既有结果，须先由顾明岚/傅景确认
- **B-02**（PASS）：无误报
- **B-03**（PASS）：关键：不得据缺失值推断「没占档」（f31）
- **B-04**（PASS）：输入校验在编号生成层完成
- **B-05**（PASS）：缺字段时不做装卸口推断
- **B-06**（PASS）：注意：CSV 读入时空字段会转为 None，因此「没填」与「确认无」必须分列

本场景 **5 条通过、1 条记为已知口径、0 条失败**，通过率 100.0%，合计耗时 0.28 ms。
