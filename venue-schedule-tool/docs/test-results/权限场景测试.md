# 权限场景测试

> **企业名称与公开业务方向有公开来源；人物、档期单号、时刻与指标均为演练虚构，不代表企业实际情况。演练结果不得作为实际业务指令（f40），正式结论须授权人员确认（f41）。**

- 项目：上海东浩会展经营有限公司 · 场馆排期与需求变更数智化试点（演练）
- 版本 / 日期：v1.0 / 2026-11-06
- 执行器：`scripts/run_scenario_tests.py`（真实调用 src/ 模块，无 mock）
- 说明：本场景共 5 条用例；图见文末附图。

## 一、场景目标与量化阈值

验证授权确认、默认收紧与来源不清的拒绝路径

| 指标 | 数值 |
| --- | --- |
| 用例总数 | 5 |
| 通过（PASS） | 5 |
| 已知口径（KNOWN） | 0 |
| 失败（FAIL） | 0 |
| 通过率（PASS / PASS+FAIL） | 100.0% |
| 合计实测耗时 | 0.06 ms |
| 单条最长耗时 | 0.02 ms |

> 判定口径：符合预设阈值记 PASS；不符合记 FAIL；实测符合当前实现但业务口径尚待书面确认的记 KNOWN，不计入通过率分母。

| 项 | 值 |

| 红线基线 | 只提示不锁档（f05/f52）、授权确认（f41）、来源留痕（f40）、三态区分（f31） |

## 三、测试过程（逐条）

### P-01 非授权人员请求作正式结论

| 项 | 内容 |
| --- | --- |
| 输入 / 操作 | request_authorization(reviewer='林亦舟') |
| 预期行为 | 返回 ok=False / code=5101 |
| 量化阈值 | 拒绝 =1 |
| **实测输出** | ok=False code=5101 |
| 实测指标 | ok=False；code=5101 |
| 耗时 | 0.01 ms |
| **判定** | **PASS** |
| 备注 / 发现 | 仅傅景 / 顾明岚有权作正式结论 |

### P-02 授权人员请求确认

| 项 | 内容 |
| --- | --- |
| 输入 / 操作 | request_authorization(reviewer='傅景') |
| 预期行为 | 返回 ok=True，状态 awaiting_approval，不代为确认 |
| 量化阈值 | 通过 =1；状态 =awaiting_approval |
| **实测输出** | ok=True status=awaiting_approval |
| 实测指标 | ok=True；status=awaiting_approval；reviewer=傅景 |
| 耗时 | 0.01 ms |
| **判定** | **PASS** |
| 备注 / 发现 | 只登记请求，不代替授权人决定 |

### P-03 授权清单为空时默认收紧

| 项 | 内容 |
| --- | --- |
| 输入 / 操作 | ReviewLedger(authorized_reviewers=set()).can_finalize('傅景') |
| 预期行为 | 返回 False（无清单不放行） |
| 量化阈值 | can_finalize=False |
| **实测输出** | can_finalize('傅景')=False |
| 实测指标 | 结果=False |
| 耗时 | 0.01 ms |
| **判定** | **PASS** |
| 备注 / 发现 | 默认收紧：审批人清单未确认前不放行（f41） |

### P-04 无来源冲突不得确认正式结论

| 项 | 内容 |
| --- | --- |
| 输入 / 操作 | Conflict(sources=[]) + ledger.finalize(reviewer='傅景') |
| 预期行为 | 抛 PermissionError（f40） |
| 量化阈值 | 异常类型 =PermissionError |
| **实测输出** | PermissionError: 来源不清的提示不得进入正式流转（f40） |
| 实测指标 | 异常类型=PermissionError |
| 耗时 | 0.02 ms |
| **判定** | **PASS** |
| 备注 / 发现 | 来源不清的提示拒绝进入正式流转 |

### P-05 清单外人员不得确认

| 项 | 内容 |
| --- | --- |
| 输入 / 操作 | ledger 授权清单={'傅景'}，finalize(reviewer='叶书') |
| 预期行为 | 抛 PermissionError（f41） |
| 量化阈值 | 异常类型 =PermissionError |
| **实测输出** | PermissionError: 叶书 不在授权人员清单内，无法确认正式结论（f41） |
| 实测指标 | 异常类型=PermissionError |
| 耗时 | 0.01 ms |
| **判定** | **PASS** |
| 备注 / 发现 | 清单外人员无法确认正式结论 |

## 四、实测发现与结论

- **P-01**（PASS）：仅傅景 / 顾明岚有权作正式结论
- **P-02**（PASS）：只登记请求，不代替授权人决定
- **P-03**（PASS）：默认收紧：审批人清单未确认前不放行（f41）
- **P-04**（PASS）：来源不清的提示拒绝进入正式流转
- **P-05**（PASS）：清单外人员无法确认正式结论

本场景 **5 条通过、0 条记为已知口径、0 条失败**，通过率 100.0%，合计耗时 0.06 ms。
